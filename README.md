## 📌 Project Overview
An end-to-end business intelligence dashboard built to track core retail analytics for AdventureWorks. The report monitors global financial performance, sales trends, regional distribution, and product/customer profitability across multiple interactive pages.

## 📊 Dashboard Pages & Previews

### 1. Executive Dashboard 📈
High-level overview displaying total revenue ($24.9M), profit ($10.5M), total orders (25.2K), and return rate. It features revenue trending over time and category-wise performance breakdowns.
![Exec Dashboard Preview](Dashboard%20Images/Exec%20Dashboard.png)

### 2. Geospatial Map Analysis 🗺️
Tracks performance metrics and regional distribution geographically.
![Map Preview](Dashboard%20Images/Map.png)

### 3. Product Details 🛍️
Deep-dive analytics into product lines, top-selling items, and return rates.
![Product Detail Preview](Dashboard%20Images/Product%20Detail.png)

### 4. Customer Insights 👤
Analyzes customer purchasing behaviors, top spenders, and segment values.
![Customer Detail Preview](Dashboard%20Images/Customer%20Detail.png)

## 🗄️ Data Modeling & Architecture
The backend utilizes a robust relational star schema connecting transactional sales facts with dimensional tables for products, customers, geography, and dates.

![Data Model](Dashboard%20Images/Data%20Modeling.png)

## 🛠️ Technical Stack & Workflow
- **Business Intelligence:** Power BI Desktop
- **Data Transformation:** Power Query for ETL and data shaping.
- **Data Modeling:** Star Schema relational architecture connecting fact tables with dimensions.
- **DAX Measures:** Custom calculations for dynamic metrics, trend analyses, and financial indicators.
